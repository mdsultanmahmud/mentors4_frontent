# 🚀 Mentors4Data

🌐 [Live Website](https://mentors4data.netlify.app/)

Mentors4Data is a modern startup landing page offering two major services: **Data Analysis** and **Web Development**. It’s designed to attract potential clients who need professional help with analyzing their datasets or building a custom website. Built entirely with **React** and **Tailwind CSS**, this project showcases a sleek design, interactive animations, and user-focused functionality — all without any backend integration.

---

## 🛠️ Tech Stack

- **React.js** – Frontend JavaScript library
- **Tailwind CSS** – Utility-first CSS framework

---

## 📸 Features

- ⚡ A clean and modern landing page  
- 🎞️ Interactive hero section with animated slider  
- ❓ FAQ section with smooth toggle animation  
- 🦶 A detailed and responsive footer  
- 📚 Filtering **Courses** page  
- 📝 Filtering **Blog** page  

---

## 🚀 Getting Started

To run this project locally, follow these steps:

```bash
git clone https://github.com/mdsultanmahmud/mentors4_frontent.git
cd mentors4_frontent
npm install
npm run dev
````
